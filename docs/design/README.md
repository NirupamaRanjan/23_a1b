# CareConnect design

Editable design: [CareConnect in Figma](https://www.figma.com/design/oLQsqeeZ1jQjSa7gCEcdfh/CareConnect?node-id=1-1102).

- `wireframes/`: the six supplied SVG wireframes with location examples updated to India, viewable offline.
- `user_descriptions.md`: patient/staff workflows, current interaction decisions and responsive behaviour.

The Figma file could not be inspected in this environment. These SVGs are retained project
wireframes with updated coordinate examples, not newly exported or verified copies of that Figma file. Their illustrative data,
fixed artboards and original date/layout examples are design records, not live data or final screenshots.
The user descriptions document the updated location, dates and empty states. Figma access is
controlled by its owner; make the link viewable by submission reviewers if required.

The supplied folder requirement says wireframes and user descriptions without prescribing a
format; both the editable link and offline SVGs are included. Follow any additional rubric supplied
by the instructor.
